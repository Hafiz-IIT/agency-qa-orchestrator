# Evaluation

## Question
Can explicit requirement-to-artifact traceability reduce false 'done' states in AI-assisted delivery workflows?

## Metrics
- Requirement coverage
- Verification coverage
- False-ready rate
- Unverified criterion count
- Reviewer reproducibility

## Falsification
- A missing requirement still yields ready=true.
- A failed criterion is ignored.
- An unknown criterion can be marked verified.
